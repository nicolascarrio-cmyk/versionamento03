# Exercícios com Vetores em Java

## Descrição

Este projeto contém a resolução de três exercícios utilizando vetores, com o objetivo de praticar armazenamento de dados em arrays, estruturas de repetição e processamento de informações.

## Exercícios

### 1. Média de idade de 8 pessoas

Desenvolva um programa que:

- Leia a idade de 8 pessoas;
- Armazene as idades em um vetor;
- Calcule a média das idades informadas;
- Exiba a média ao final da execução.

### 2. Posições das pessoas com mais de 25 anos

Desenvolva um programa que:

- Leia a idade de 7 pessoas;
- Armazene as idades em um vetor;
- Verifique quais posições possuem pessoas com idade superior a 25 anos;
- Exiba as posições encontradas.

### 3. Múltiplos de 10 em um vetor

Desenvolva um programa que:

- Leia 15 números inteiros;
- Armazene os valores em um vetor;
- Mostre todos os números armazenados;
- Indique em quais posições foram digitados valores múltiplos de 10.

## Tecnologias utilizadas

- Java
- Vetores (Arrays)
- Estruturas de repetição (`for`)
- Estruturas condicionais (`if`)

## Objetivo

Praticar os conceitos fundamentais de programação com vetores, incluindo:

- Armazenamento de dados em arrays;
- Percorrer vetores utilizando laços de repetição;
- Realizar cálculos e verificações em elementos armazenados;
- Manipular posições e valores dentro de um vetor.
